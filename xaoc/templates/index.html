PC Tutorial

1. Open Discord Web

Log into your account using a web browser (Chrome, Edge, Firefox) on your computer. Do not use the desktop app.

2. Open Developer Tools

Press F12 on your keyboard or right-click anywhere and select "Inspect".

3. Find Local Storage

Go to the Application tab (or Storage in Firefox) and expand Local Storage. Select https://discord.com.

4. Copy the Token

Find the key named token. Right-click the value next to it and copy it.



Mobile Tutorial

Option 1: Using Kiwi Browser (Android)

Download Kiwi Browser from the Play Store. Open Discord in Kiwi, tap the 3 dots in the top right, scroll down to "Developer Tools", and follow the exact same steps as the PC tutorial.

Option 2: Using a PC (iOS & Android)

If you are on iOS (Safari) or don't want to download another browser, the easiest way is to log into Discord web on a computer, grab the token using the PC steps above, and simply email or DM the token to yourself to paste into this dashboard.



Common Errors

Improper Token

You likely copied a Bot Token from the Developer Portal instead of a User Token. Follow the steps above exactly.

Process Closes Instantly

Check your terminal. You may be missing dependencies. Run pip install -r requirements.txt.
